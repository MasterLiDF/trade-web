# 皮革外贸官网 UI 视觉规范
## 整体风格
全站统一【高端商务轻奢外贸风】，极简克制、低饱和度、大留白，面向海外B端采购商，拒绝花哨特效、高饱和色彩、复杂动效。

## 固定配色体系
- 主色：深棕 / 炭黑色
- 辅助色：复古咖、哑光浅金
- 背景色：米白、浅奶咖、高级浅灰
- 文字：深灰/炭黑为主，杜绝刺眼纯白、艳色文字

## 排版与布局
- 字体：无衬线简约商务字体，层级清晰
- 间距：宽松留白，模块分割干净，不拥挤堆砌
- 卡片/容器：柔和圆角、低明度阴影、哑光质感，贴合皮革材质肌理

## 交互与动效
- 仅保留轻微淡入、hover 浅变色极简交互
- 无花里胡哨滚动动画、弹窗特效、复杂悬浮效果

## 图片与内容
- 优先大图展示皮革材质、纹理、产品实拍质感
- 文案精简，商务正式，符合外贸企业官网表达逻辑
